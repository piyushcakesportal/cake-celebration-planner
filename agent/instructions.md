Role

You are a senior full-stack developer and UI/UX designer. Build a polished, mobile-responsive web application called “Cake Celebration Planner.”

Purpose

The application helps users choose the right cake for a celebration based on occasion, guest count, preferred flavour, budget and delivery timing. It must function as a genuinely useful planning tool, not merely a promotional landing page.

Main Features
Create an interactive cake recommendation form with these fields:
Occasion: Birthday, Anniversary, Wedding, Farewell, Baby Shower or Other
Number of guests
Preferred flavour
Cake type: Regular, Photo, Designer, Eggless or Theme Cake
Budget range
Required delivery date
Preferred delivery timing: Standard, Fixed Time or Midnight
After submission, display:
Recommended cake weight
Suitable cake type
Two or three flavour suggestions
Estimated serving range
A short personalised recommendation
Celebration preparation checklist
Add a cake serving calculator:
0.5 kg: approximately 4–6 people
1 kg: approximately 8–12 people
1.5 kg: approximately 12–18 people
2 kg: approximately 18–24 people
3 kg: approximately 25–35 people
Clearly state that serving estimates can vary depending on slice size.
Add helpful content sections:
How to Choose the Right Cake
Cake Weight and Serving Guide
Popular Cakes for Different Occasions
Tips for Ordering Personalised Cakes
Frequently Asked Questions
Include one natural call-to-action near the recommendations:
“Want to explore more designs? Browse cakes online.”
Link “Browse cakes online” to:
https://cakesportal.in/
Design
Use a modern bakery-inspired design.
Use soft cream, warm pink and chocolate-brown colours.
Include attractive cake illustrations or royalty-free cake images.
Use cards, rounded corners, subtle shadows and readable typography.
Make the interface clean and professional.
Avoid excessive animations, pop-ups and promotional banners.
Ensure excellent mobile responsiveness and accessibility.
Technical Requirements
Build using Next.js, TypeScript and Tailwind CSS.
Use reusable components and clean project structure.
Perform calculations locally without requiring a database.
Validate all form inputs.
Add appropriate metadata, page title and meta description.
Use semantic HTML with one H1 and logically structured H2 headings.
Add Open Graph metadata.
Add FAQ structured data in valid JSON-LD.
Add a sitemap.xml and robots.txt.
Make sure all buttons, calculators and form interactions work.
Do not use placeholder text, broken links or unfinished sections.
Keep the external link natural and do not repeat it throughout the application.
Prepare the project for direct deployment on Vercel.
